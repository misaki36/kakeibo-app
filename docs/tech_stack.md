# 技術選定資料

## 使用技術一覧

### バックエンド
| 技術 | バージョン | 選定理由 |
|---|---|---|
| PHP | 8.3 | Laravelの動作に必要。最新の安定版 |
| Laravel | 12.x | 日本語情報が豊富。認証・DB操作が簡単に実装できる |
| MySQL | 8.0 | 安定性が高く、Laravelとの相性が良い |

### フロントエンド
| 技術 | 選定理由 |
|---|---|
| Blade | Laravelに標準搭載。別途学習コストが不要 |
| Tailwind CSS | クラスを書くだけでデザインできる。初心者でも使いやすい |
| Alpine.js | 軽量でBladeと相性が良い。簡単な動的UIに対応できる |

### インフラ
| 技術 | 選定理由 |
|---|---|
| Docker | 開発環境を統一できる。Week16で学習済み |
| Render | 無料プランあり。GitHubと連携して簡単にデプロイできる |
| AWS S3 | レシート画像の保存先。無料枠で利用可能 |

### 開発ツール
| 技術 | 選定理由 |
|---|---|
| Git / GitHub | バージョン管理。チーム開発の標準ツール |
| Claude Code | AIによるコード補助。開発効率を上げる |
| Laravel Debugbar | デバッグを効率化するLaravel専用ツール |
| PHPUnit | Laravelに標準搭載のテストツール |

## 選定しなかった技術

| 技術 | 選定しなかった理由 |
|---|---|
| React / Vue.js | 学習コストが高い。Bladeで十分対応可能 |
| PostgreSQL | MySQLで十分。学習コストを下げるため |
| AWS EC2 | 無料枠の制限あり。Renderの方が初心者向け |
